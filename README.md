# Obsługa peryferiów mikrokontrolera NXP LPC2000 (Embedded C)

Projekt zawiera moje programy napisane w języku C, realizowane w ramach ćwiczeń laboratoryjnych przedmiotu "Podstawy programowania systemów wbudowanych". 
Programy obsługują podstawowe peryferia mikrokontrolera z rodziny NXP LPC2000 w środowisku Keil uVision 4.
W repozytorium można znaleźć programy korzystające między innymi z: GPIO, maszyny stanów, timerów czy przerwań.
